## How I lead

I grew from SDE III to Technical Lead at Applore by doing one thing consistently: making teams ship predictable, measurable outcomes. These are the standards I hold myself and my team to.

| Principle                           | In practice                                                                                                                                                                                       |
|:------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Architecture before velocity**    | Clean Architecture, Bloc / Provider / GetX conventions and build flavors are set up front, so the team moves fast without stepping on each other and features land with far fewer regressions.    |
| **Mentorship is a multiplier**      | Pairing, thorough code review and Flutter knowledge-sharing sessions. The goal is engineers who make the right call when I am not in the room.                                                    |
| **Observability from release one**  | Crashlytics, Sentry and Firebase Analytics ship with the first build, not the fifth. Stability is a tracked number, not a feeling.                                                                 |
| **Automate the path to production** | Fastlane and Codemagic pipelines, flavored builds and CI/CD, so releases are routine, frequent and low-drama.                                                                                      |
| **Measure outcomes, not output**    | Retention, satisfaction, load time and engagement are the KPIs I report against. Story points are a means, never the goal.                                                                        |
| **Own the whole problem**           | Flutter, Node.js, data and AI agents: I go wherever the blocker is, and I keep business, product and design in one Agile loop.                                                                     |
| **Users first, always**             | Every JK Tyre dealer, RuLoans partner and IELTS learner has a job to do. Design and prioritisation decisions start there.                                                                          |
